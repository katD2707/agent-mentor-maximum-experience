# Spaced practice scheduler (one student)

Use when placing new lessons and review sessions across the 7-day plan.
- Start pattern for a newly finished lesson: first review 1-3 days later, second 1-2 weeks later, third 3-4 weeks later. These are starting points, not laws; the student's own right/wrong data (due items, mastery) overrides them. Say so in the reason when you depart from the pattern.
- Review is retrieval (a few quiz questions, recall from memory), not re-reading or re-teaching. Use kind "review" or "practice".
- Keep 10-15 minutes of a longer session for retrieval of older material before new content; short sessions can be review only.
- Do not cram: with an exam date, every topic gets a retrieval slot in the last 5 days, but the earlier weeks carry the spacing.
- Harder topics (low mastery) get more review slots; well-retained topics fewer.
- Mix topics of the same domain in one review session when they are easy to confuse (see interleaving).

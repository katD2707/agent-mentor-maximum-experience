# Interleaving across the week

Use when the student has several courses or topics in the week.
- Teach each lesson in a focused block first; interleave afterwards, as practice, not as first exposure.
- Interleave related but distinct topics (they force the student to decide which idea applies). Do not mix unrelated subjects inside one short session; interleave across days instead (Monday Physics, Tuesday Maths, Wednesday Physics review).
- Start with two topics, add more gradually. Respect prerequisites: lessons stay in course order.
- Expect it to feel harder; do not drop it for that reason alone.
- With one course only, interleave earlier lessons into practice and review sessions.
